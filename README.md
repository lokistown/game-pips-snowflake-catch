# Pip's Snowflake Catch

Help Pip catch magical glowing snowflakes in the cozy plaza before they touch the ground! Watch out for chilly icicles while gathering warm winter stars.

**How to play:** Use Left/Right arrows, A/D, or drag/touch the screen to catch snowflakes in Pip's basket.
